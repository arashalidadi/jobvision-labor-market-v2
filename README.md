# تحلیل داده آگهی‌های استخدامی جاب‌ویژن — بازنویسی کامل (v2)

پروژهٔ تحلیل بازار کار ایران بر پایهٔ آگهی‌های استخدامی پلتفرم **جاب‌ویژن** (Hugging Face: [JobVision_Jobposts_Dataset](https://huggingface.co/datasets/JobVision/JobVision_Jobposts_Dataset)).

این مخزن، نسخهٔ بازنویسی‌شدهٔ پروژه از ابتداست که در آن همهٔ مراحل — از پیش‌پردازش تا مدل‌سازی، گزارش مکتوب و ارائه — دوباره و به‌صورت گام‌به‌گام ساخته می‌شود.

**وضعیت فعلی:** مرحلهٔ آغاز (نسخهٔ خام) — ساختار اولیهٔ پروژه، صورت پروژه و راهنمای داده ایجاد شده و نخستین کامیت ثبت شده است.

---

## ساختار پوشه‌ها

| مسیر | توضیح |
| --- | --- |
| `docs/project-brief.md` | صورت پروژه؛ عیناً متن اعلام‌شدهٔ استاد + پیوست معرفی داده |
| `data/README.md` | راهنمای داده: محل دریافت، مشخصات و مجوز (فایل CSV در گیت نگهداری نمی‌شود) |

پوشه‌های تحلیلی (نوتبوک، اسکریپت‌ها، خروجی‌ها، گزارش و ارائه) در گام‌های بعدی و به‌ترتیب افزوده می‌شوند.
